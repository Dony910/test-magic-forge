# 콘텐츠 기획서 작성 가이드

`doc_type: content`

콘텐츠 기획서는 **반복적으로 제작·추가·운영되는 게임 내용의 규격**을 정의합니다. NPC, 원소, 무기 종류, 파츠, 퀘스트, 대사, 이벤트 등이 대상입니다.

## 목차별 작성 가이드

| 목차 | 무엇을 작성하는가 | 간단한 예시 |
| --- | --- | --- |
| 1. 콘텐츠 목적 | 이 콘텐츠가 어떤 플레이 경험을 만들기 위해 존재하는지 적습니다. | `무기 소분류와 파츠는 스케치 결과의 다양성을 실제 자산으로 연결한다.` |
| 2. 플레이 경험 | 콘텐츠를 접했을 때 플레이어가 무엇을 보고 선택하고 느끼는지 적습니다. | `같은 검을 만들어도 대검·단검 등 서로 다른 결과를 발견한다.` |
| 3. 콘텐츠 분류 체계 | 대분류/소분류/등급/유형 등 콘텐츠를 나누는 기준을 정의합니다. | `검 > 대검 > 칼날/가드/손잡이` |
| 4. 제작 규칙 | 새 콘텐츠를 추가할 때 지켜야 하는 네이밍, 구성, 필수 요소 규칙을 적습니다. | `대검은 칼날·가드·손잡이를 필수로 가진다.` |
| 5. 데이터 스키마 | 콘텐츠 한 건이 가져야 하는 필드를 설명합니다. | `part_id`, `weapon_subtype`, `part_type`, `required` |
| 6. 콘텐츠 목록 | 현재 실제로 존재하는 콘텐츠를 표로 정리하거나 Data 문서로 링크합니다. | `대검 / 양날형 대검날 / DOUBLE_EDGE_BLADE_L` |
| 7. 해금/노출 조건 | 콘텐츠가 언제 등장하고 사용할 수 있는지 적습니다. | `상점 레벨 3부터 창 계열 해금` |
| 8. 밸런스 및 품질 기준 | 콘텐츠 간 편차와 최소 품질 기준을 정의합니다. | `각 무기 소분류는 최소 2개 이상의 칼날 후보를 확보한다.` |
| 9. 운영 및 추가 제작 규칙 | 라이브/업데이트 때 콘텐츠를 추가·수정·폐기하는 절차를 적습니다. | `기존 part_id는 재사용하지 않고 Deprecated 처리한다.` |
| 10. 예시 | 작성 규칙을 적용한 완성 콘텐츠 한두 건을 보여줍니다. | `단검: 칼날 + 손잡이, 가드 없음` |
| 11. 미확정 항목 | 아직 결정되지 않은 콘텐츠 정책을 적습니다. | `초기 무기 대분류 개수 TBD` |
| 변경 이력 | 분류 체계, 제작 규칙, 목록 정책 변경을 기록합니다. | `v0.2.0: 세부 무기 종류를 자동 판정 대상으로 변경` |

## 최소 Markdown 골격

```md
# 콘텐츠명

## 1. 콘텐츠 목적
## 2. 플레이 경험
## 3. 콘텐츠 분류 체계
## 4. 제작 규칙
## 5. 데이터 스키마
## 6. 콘텐츠 목록
## 7. 해금/노출 조건
## 8. 밸런스 및 품질 기준
## 9. 운영 및 추가 제작 규칙
## 10. 예시
## 11. 미확정 항목
## 변경 이력
```

## 콘텐츠 기획서와 Data 문서 구분

콘텐츠 기획서는 **규칙과 의미**를 설명합니다. 수백 개의 실제 행이나 운영 테이블은 `doc_type: data` 문서 또는 CSV/Sheet로 분리하고 콘텐츠 기획서에서 링크합니다.
