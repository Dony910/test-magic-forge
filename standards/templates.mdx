# 문서 종류 선택 가이드

이 페이지는 **어떤 종류의 문서를 작성해야 하는지 선택하는 인덱스**입니다. 각 문서의 실제 목차별 작성법과 예시는 하위 문서에서 확인합니다.

## 문서 종류

| 문서 | `doc_type` | 핵심 질문 | 상세 가이드 |
| --- | --- | --- | --- |
| PRD | `prd` | 왜 이 제품을 만들고 무엇을 검증하는가? | [PRD 작성 가이드](/standards/document-types/prd) |
| GDD | `gdd` | 게임 전체가 어떤 경험과 구조로 작동하는가? | [GDD 작성 가이드](/standards/document-types/gdd) |
| 시스템 기획서 | `system` | 특정 시스템은 왜 존재하고 어떤 규칙으로 작동하는가? | [시스템 기획서 작성 가이드](/standards/document-types/system) |
| 콘텐츠 기획서 | `content` | 반복 제작되는 게임 콘텐츠는 어떤 규격을 따르는가? | [콘텐츠 기획서 작성 가이드](/standards/document-types/content) |
| 기능정의서 | `feature` | 개발자가 무엇을 어떤 입출력·상태·예외로 구현해야 하는가? | [기능정의서 작성 가이드](/standards/document-types/feature) |
| WBS | `wbs` | 누가 무엇을 언제까지 어떤 완료 기준으로 수행하는가? | [WBS 작성 가이드](/standards/document-types/wbs) |
| Decision | `decision` | 충돌하는 선택지 중 무엇을 왜 결정했는가? | [Decision 작성 가이드](/standards/document-types/decision) |
| Data | `data` | 실제 데이터의 필드·값·제약·목록 기준은 무엇인가? | [Data 작성 가이드](/standards/document-types/data) |

## 빠른 선택 기준

- **게임의 존재 이유/타깃/MVP 검증**을 바꾸려면 → PRD
- **코어 루프/메타 루프/전체 게임 구조**를 바꾸려면 → GDD
- **원소·태그·무기 같은 게임 규칙**을 바꾸려면 → 시스템 기획서
- **NPC·무기 종류·파츠 목록처럼 반복 제작될 내용**을 정의하면 → 콘텐츠 기획서
- **클라이언트/서버/AI 구현 단위와 상태**를 정의하면 → 기능정의서
- **일정·담당·선행 작업**을 관리하면 → WBS
- **문서 간 충돌이나 중요한 정책 선택**을 기록하면 → Decision
- **DB/CSV/Sheet 필드와 실제 값**을 관리하면 → Data

## 문서 간 관계 예시

```text
PRD
└─ GDD
   ├─ 태그 시스템 기획서
   │  ├─ 태그 기능정의서
   │  └─ 태그 Data
   ├─ 무기 시스템 기획서
   │  ├─ 무기 콘텐츠 기획서
   │  ├─ 무기 모듈 기능정의서
   │  └─ 파츠 Data
   └─ 무기 제작 시스템 기획서
      └─ 무기 제작 기능정의서

Decision → 위 문서들의 정책 변경 근거
WBS → 위 산출물의 작업 일정과 담당 관리
```

하위 문서에서는 각 목차에 **무엇을 적어야 하는지, 짧은 예시, 최소 Markdown 골격, 넣지 않아야 하는 내용**을 함께 제공합니다.
