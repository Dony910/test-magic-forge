# Front Matter 규격

모든 기획 문서는 아래 Front Matter를 가진다. 필수 필드는 Agent가 생성 및 수정 시 검증한다.

```yaml
---
title: 문서 제목
doc_type: system
status: draft
version: 0.1.0
owner: 이름 또는 팀
created: 2026-08-24
updated: 2026-08-24
scope: mvp
tags:
  - weapon
related:
  - /systems/elements/overview
supersedes: null
superseded_by: null
deprecated: false
---
```

## 필수 필드

| 필드 | 설명 | 허용값/규칙 |
| --- | --- | --- |
| `title` | 문서 제목 | 비어있을 수 없음 |
| `doc_type` | 문서 종류 | `prd`, `gdd`, `system`, `content`, `feature`, `wbs`, `decision`, `data` |
| `status` | 문서 상태 | `draft`, `review`, `approved`, `deprecated` |
| `version` | 문서 버전 | Semantic Versioning 형식 권장 |
| `owner` | 책임자 | 개인 또는 팀 |
| `created` | 최초 생성일 | `YYYY-MM-DD` |
| `updated` | 최종 의미 변경일 | `YYYY-MM-DD` |
| `scope` | 적용 범위 | `poc`, `prototype`, `mvp`, `post-mvp`, `live` |
| `deprecated` | 폐기 여부 | `true` 또는 `false` |

## 선택 필드

- `tags`: 검색 및 분류용 태그
- `related`: 직접 연관된 문서 경로
- `supersedes`: 이 문서가 대체한 이전 문서
- `superseded_by`: 이 문서를 대체하는 신규 문서
- `source`: Google Docs/Sheets 등 원본 출처
- `reviewers`: 검토자 목록

## 강제 규칙

- `deprecated: true`이면 `status`는 반드시 `deprecated`여야 한다.
- Deprecated 문서는 가능한 경우 `superseded_by`를 지정한다.
- `status: approved` 문서의 핵심 결정은 Agent가 임의로 변경하지 않는다.
- 의미 변경에는 반드시 `updated`를 갱신한다.
- 확인할 수 없는 값은 추측하지 않고 `TBD`로 남긴다.
