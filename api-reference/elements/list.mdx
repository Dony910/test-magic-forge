List all game elements within a specific project. Use query parameters to filter by type, tag, or paginate through large result sets. Game elements include characters, items, abilities, levels, and any custom types you have defined.

## Endpoint

```http
GET https://api.magic-forge.com/v1/projects/{projectId}/elements
```

## Authentication

Include your API key in every request using the `Authorization` header. You can generate an API key from your [Magic Forge dashboard](https://app.magic-forge.com/settings/api-keys).

```http
Authorization: Bearer YOUR_API_KEY
```

## Path parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project whose elements you want to list.
</ParamField>

## Query parameters

<ParamField query="type" type="string">
  Filter by element type. Accepted values: `character`, `item`, `ability`, `level`, `custom`.
</ParamField>

<ParamField query="tag" type="string">
  Filter by a specific tag. Only elements that include this tag are returned.
</ParamField>

<ParamField query="limit" default="20" type="integer">
  Maximum number of elements to return per page. Minimum `1`, maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from a previous response. Use this to fetch the next page of results.
</ParamField>

## Request

<CodeGroup>

```bash curl
curl -X GET "https://api.magic-forge.com/v1/projects/proj_abc123/elements?type=character&limit=10" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```python Python
import requests

url = "https://api.magic-forge.com/v1/projects/proj_abc123/elements"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
params = {
    "type": "character",
    "limit": 10
}

response = requests.get(url, headers=headers, params=params)
print(response.json())
```

```javascript JavaScript
const response = await fetch(

```

</CodeGroup>

## Response fields

<ResponseField name="data" type="array">
  Array of game element objects.
</ResponseField>

<ResponseField name="data[].id" type="string">
  Unique identifier for the element.
</ResponseField>

<ResponseField name="data[].projectId" type="string">
  The project this element belongs to.
</ResponseField>

<ResponseField name="data[].type" type="string">
  The element type: `character`, `item`, `ability`, `level`, or `custom`.
</ResponseField>

<ResponseField name="data[].name" type="string">
  The display name of the element.
</ResponseField>

<ResponseField name="data[].description" type="string">
  A detailed description of the element.
</ResponseField>

<ResponseField name="data[].attributes" type="object">
  Key-value map of custom attributes specific to this element.
</ResponseField>

<ResponseField name="data[].tags" type="array">
  Array of string tags for categorization and filtering.
</ResponseField>

<ResponseField name="data[].createdAt" type="string">
  ISO 8601 timestamp of when the element was created.
</ResponseField>

<ResponseField name="data[].updatedAt" type="string">
  ISO 8601 timestamp of the last update.
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata for result sets that span multiple pages.
</ResponseField>

<ResponseField name="pagination.limit" type="integer">
  Number of elements returned in this page.
</ResponseField>

<ResponseField name="pagination.nextCursor" type="string">
  Cursor to pass as the `cursor` query param for the next page. Omitted when `hasMore` is `false`.
</ResponseField>

<ResponseField name="pagination.hasMore" type="boolean">
  Whether additional pages of results are available.
</ResponseField>

## Errors

| Status | Error code | Description |
| --- | --- | --- |
| `400` | `invalid_request` | One or more query parameters are malformed or invalid. |
| `401` | `unauthorized` | The API key is missing or invalid. |
| `403` | `forbidden` | The API key does not have permission to access this project. |
| `404` | `not_found` | The specified project does not exist. |
| `429` | `rate_limited` | You have exceeded the request rate limit. Retry after the time specified in the `Retry-After` header. |
