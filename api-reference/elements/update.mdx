Update an existing game element. This endpoint supports partial updates: you only need to include the fields you want to change. Fields that are omitted remain unchanged. Use this to refine stats, adjust descriptions, or retag elements as your design evolves.

## Endpoint

```http
PATCH https://api.magic-forge.com/v1/projects/{projectId}/elements/{elementId}
```

## Authentication

Include your API key in every request using the `Authorization` header. You can generate an API key from your [Magic Forge dashboard](https://app.magic-forge.com/settings/api-keys).

```http
Authorization: Bearer YOUR_API_KEY
```

## Path parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project that contains the element.
</ParamField>

<ParamField path="elementId" type="string" required>
  The unique identifier of the element to update.
</ParamField>

## Body parameters

<ParamField body="name" type="string">
  New display name for the element. Must be between 1 and 120 characters.
</ParamField>

<ParamField body="description" type="string">
  New detailed description. Maximum 10,000 characters. Pass an empty string to clear the description.
</ParamField>

<ParamField body="attributes" type="object">
  Key-value map of attributes to merge into the existing attribute set. Only the keys you provide are updated; existing keys that are omitted remain unchanged. To remove an attribute, set its value to `null`.
</ParamField>

<ParamField body="tags" type="array">
  Array of string tags to replace the existing tags. If provided, this overwrites the entire tag list.
</ParamField>

<Note>
  The `attributes` object is **merged**, not replaced. Only the attribute keys you include in the request body are updated. Existing attributes that are omitted remain unchanged. To remove an attribute, set its value to `null`.
</Note>

## Request

<CodeGroup>

```bash curl
curl -X PATCH "https://api.magic-forge.com/v1/projects/proj_abc123/elements/elm_char_001" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sir Aldric the Valiant",
    "attributes": {
      "health": 135,
      "armor": 12
    },
    "tags": ["playable", "melee", "tank", "legendary"]
  }'
```

```python Python
import requests

url = "https://api.magic-forge.com/v1/projects/proj_abc123/elements/elm_char_001"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
payload = {
    "name": "Sir Aldric the Valiant",
    "attributes": {
        "health": 135,
        "armor": 12
    },
    "tags": ["playable", "melee", "tank", "legendary"]
}

response = requests.patch(url, headers=headers, json=payload)
print(response.json())
```

```javascript JavaScript
const response = await fetch(
  "https://api.magic-forge.com/v1/projects/proj_abc123/elements/elm_char_001",
  {
    method: "PATCH",
    headers: {
      "Authorization": "Bearer YOUR_API_KEY",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      name: "Sir Aldric the Valiant",
      attributes: {
        health: 135,
        armor: 12
      },
      tags: ["playable", "melee", "tank", "legendary"]
    })
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

## Response

A successful request returns a `200 OK` status code and the updated element.

```json 200 OK
{
  "id": "elm_char_001",
  "projectId": "proj_abc123",
  "type": "character",
  "name": "Sir Aldric the Valiant",
  "description": "A veteran knight with unwavering loyalty to the crown.",
  "attributes": {
    "health": 135,
    "strength": 18,
    "speed": 12,
    "isPlayable": true,
    "armor": 12
  },
  "tags": ["playable", "melee", "tank", "legendary"],
  "createdAt": "2024-01-15T09:30:00Z",
  "updatedAt": "2024-06-10T16:45:00Z"
}
```

## Response fields

<ResponseField name="id" type="string">
  Unique identifier for the element.
</ResponseField>

<ResponseField name="projectId" type="string">
  The project this element belongs to.
</ResponseField>

<ResponseField name="type" type="string">
  The element type: `character`, `item`, `ability`, `level`, or `custom`.
</ResponseField>

<ResponseField name="name" type="string">
  The updated display name of the element.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the element.
</ResponseField>

<ResponseField name="attributes" type="object">
  The merged set of custom attributes, reflecting the partial update.
</ResponseField>

<ResponseField name="tags" type="array">
  The updated array of string tags.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp of when the element was originally created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO 8601 timestamp of the most recent update.
</ResponseField>

## Errors

| Status | Error code | Description |
| --- | --- | --- |
| `400` | `invalid_request` | A field value is invalid or malformed. |
| `401` | `unauthorized` | The API key is missing or invalid. |
| `403` | `forbidden` | The API key does not have permission to modify this project. |
| `404` | `not_found` | The specified project or element does not exist. |
| `409` | `duplicate_name` | Another element in this project already uses this name. |
| `429` | `rate_limited` | You have exceeded the request rate limit. Retry after the time specified in the `Retry-After` header. |
