Create a new game element inside a project. Game elements are the core building blocks of your game design: characters, items, abilities, levels, or any custom type you need to track. Each element has a name, optional description, typed attributes, and tags for organization.

## Endpoint

```http
POST https://api.magic-forge.com/v1/projects/{projectId}/elements
```

## Authentication

Include your API key in every request using the `Authorization` header. You can generate an API key from your [Magic Forge dashboard](https://app.magic-forge.com/settings/api-keys).

```http
Authorization: Bearer YOUR_API_KEY
```

## Path parameters

<ParamField path="projectId" type="string" required>
  The unique identifier of the project to create the element in.
</ParamField>

## Body parameters

<ParamField body="type" type="string" required>
  The element type. Must be one of: `character`, `item`, `ability`, `level`, `custom`.
</ParamField>

<ParamField body="name" type="string" required>
  The display name of the element. Must be between 1 and 120 characters.
</ParamField>

<ParamField body="description" type="string">
  A detailed description of the element. Maximum 10,000 characters.
</ParamField>

<ParamField body="attributes" type="object">
  Key-value map of custom attributes. Values can be strings, numbers, booleans, or arrays.
</ParamField>

<ParamField body="tags" type="array">
  Array of string tags for categorization. Maximum 20 tags per element, each up to 50 characters.
</ParamField>

## Request

<CodeGroup>

```bash curl
curl -X POST "https://api.magic-forge.com/v1/projects/proj_abc123/elements" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "character",
    "name": "Sir Aldric",
    "description": "A veteran knight with unwavering loyalty to the crown.",
    "attributes": {
      "health": 120,
      "strength": 18,
      "speed": 12,
      "isPlayable": true
    },
    "tags": ["playable", "melee", "tank"]
  }'
```

```python Python
import requests

url = "https://api.magic-forge.com/v1/projects/proj_abc123/elements"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
payload = {
    "type": "character",
    "name": "Sir Aldric",
    "description": "A veteran knight with unwavering loyalty to the crown.",
    "attributes": {
        "health": 120,
        "strength": 18,
        "speed": 12,
        "isPlayable": True
    },
    "tags": ["playable", "melee", "tank"]
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
```

```javascript JavaScript

```

</CodeGroup>

## Response

A successful request returns a `201 Created` status code and the newly created element.

```json 201 Created
{
  "id": "elm_char_001",
  "projectId": "proj_abc123",
  "type": "character",
  "name": "Sir Aldric",
  "description": "A veteran knight with unwavering loyalty to the crown.",
  "attributes": {
    "health": 120,
    "strength": 18,
    "speed": 12,
    "isPlayable": true
  },
  "tags": ["playable", "melee", "tank"],
  "createdAt": "2024-06-10T14:23:00Z",
  "updatedAt": "2024-06-10T14:23:00Z"
}
```

## Response fields

<ResponseField name="id" type="string">
  Unique identifier for the newly created element.
</ResponseField>

<ResponseField name="projectId" type="string">
  The project this element belongs to.
</ResponseField>

<ResponseField name="type" type="string">
  The element type: `character`, `item`, `ability`, `level`, or `custom`.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the element.
</ResponseField>

<ResponseField name="description" type="string">
  A detailed description of the element.
</ResponseField>

<ResponseField name="attributes" type="object">
  Key-value map of custom attributes specific to this element.
</ResponseField>

<ResponseField name="tags" type="array">
  Array of string tags for categorization and filtering.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp of when the element was created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO 8601 timestamp of the last update.
</ResponseField>

## Errors

| Status | Error code | Description |
| --- | --- | --- |
| `400` | `invalid_request` | A required field is missing or a field value is invalid. |
| `401` | `unauthorized` | The API key is missing or invalid. |
| `403` | `forbidden` | The API key does not have permission to modify this project. |
| `404` | `not_found` | The specified project does not exist. |
| `409` | `duplicate_name` | An element with this name already exists in the project. |
| `429` | `rate_limited` | You have exceeded the request rate limit. Retry after the time specified in the `Retry-After` header. |
