Retrieve the full details of a single project, including its metadata, element counts, collaborators, and the latest snapshot. Use this endpoint after creating a project or when navigating from a list view.

## Endpoint

```text
GET https://api.magic-forge.com/v1/projects/{id}
```

## Path parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | Yes | Unique project identifier (e.g., `proj_2K9mNpQ8rL`). |

## Example request

```bash
curl -X GET "https://api.magic-forge.com/v1/projects/proj_2K9mNpQ8rL" \
  -H "Authorization: Bearer YOUR_API_KEY"
```


<ResponseField name="collaborators" type="array">
  List of users with access to this project. Each entry includes `user_id`, `email`, `role`, and `joined_at`.
</ResponseField>

<ResponseField name="latest_snapshot" type="object">
  Summary of the most recent version snapshot, including the version number, timestamp, author, and a short change summary.
</ResponseField>

## Error responses

| Status | Code | What to check |
| --- | --- | --- |
| `404` | `not_found` | The project ID does not exist or you do not have access. |
| `403` | `forbidden` | You do not have permission to view this project. |
