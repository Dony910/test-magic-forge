---

Fetch every project you can access, with optional filters for status and tags. Use the `cursor` parameter to paginate through large workspaces.

## Endpoint

```text
GET https://api.magic-forge.com/v1/projects
```

## Request parameters

<ParamField query="status" default="all" type="string">
  Filter by project status. Options: `draft`, `active`, or `archived`.
</ParamField>

<ParamField query="tag" type="string">
  Filter by a single tag slug (case-insensitive exact match).
</ParamField>

<ParamField query="limit" default="20" type="integer">
  Number of projects to return per page. Maximum: `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque cursor for pagination. Pass the `next_cursor` value from the previous response.
</ParamField>

<ParamField query="sort" default="updated_desc" type="string">
  Sort order. Options: `created_asc`, `created_desc`, `updated_asc`, `updated_desc`, `name_asc`, `name_desc`.
</ParamField>

## Example request

```bash
curl -X GET "https://api.magic-forge.com/v1/projects?status=active&limit=10&sort=updated_desc" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
