This glossary defines the core terminology you will encounter while using Magic Forge to plan, build, and balance your games. Use it as a quick reference when navigating projects, reading the API docs, or collaborating with teammates.

<Accordion title="A — E">
  **Attribute**

  A named value that defines a property of a game element. Attributes can represent stats such as damage, health, cooldown, or cost, and are used to compare and balance elements across your design.

  **Balance Sheet**

  A visual table in Magic Forge that compares selected elements and their attributes side by side. It highlights outliers, trends, and inconsistencies so you can verify that no single element is overpowered or underpowered.

  **Collaborator**

  A teammate who has been invited to view or edit a project. Collaborators can have different permission levels, such as viewer, editor, or admin, which control what they can change within the workspace.

  **Element**

  A building block inside a Magic Forge project that represents a game entity, such as a character, weapon, ability, enemy, or level. Each element has a type, a set of attributes, and a description.
</Accordion>

<Accordion title="F — L">
  **GDD (Game Design Document)**

  A comprehensive living document that describes the vision, mechanics, systems, and content of a game. In Magic Forge, your project acts as the GDD: it holds structured game elements, balance data, and design rationale that can be exported and shared.
</Accordion>

<Accordion title="M — R">
  **Power Curve**

  A design principle that describes how the strength of game elements progresses over time or across tiers. Magic Forge visualizes power curves within balance sheets so you can ensure that rewards, difficulty, or item stats escalate in a fair and predictable way.

  **Project**

  The top-level container for all design work in Magic Forge. A project includes game elements, balance sheets, version history, and collaborator access. You can think of a project as a single game or a major subsystem you are designing.
</Accordion>

<Accordion title="S — Z">
  **Snapshot**

  A frozen copy of your project at a specific moment in time. Snapshots let you preserve milestones, such as a vertical slice or a pre-alpha build, so you can review or revert to earlier design states later.

  **Version Tag**

  A human-readable label attached to a snapshot, such as `v0.3.0` or `pre-alpha`. Version tags make it easy to identify important milestones in your project history and to communicate design changes to your team.

  **Workspace**

  Your personal or team environment inside Magic Forge. A workspace contains all the projects you own or collaborate on, along with settings for users, integrations, and billing.
</Accordion>
