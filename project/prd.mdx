# PRD

## 1. 제품 개요

**마법공방의 대장장이 (The AI Blacksmith)**는 생성형 AI를 플레이어가 직접 조작하는 제작 메커닉으로 사용하는 상점 경영 게임입니다. 플레이어는 NPC의 모호한 의뢰를 해석하고 원소와 스케치로 맞춤 무기를 제작합니다.

## 2. 문제와 기회

생성형 AI의 예측 불가능성을 단순 감상이 아닌 **추론 → 입력 → 생성 → 평가**의 게임 루프로 전환합니다. 플레이어가 결과 생성에 명확한 의도를 넣고 그 의도가 얼마나 반영됐는지 확인할 수 있어야 합니다.

## 3. 목표

### 사용자 목표
- NPC의 요구를 추론하는 재미를 제공한다.
- 원소와 손그림으로 제작 의도를 표현하게 한다.
- 생성 결과가 자신의 선택과 연결됐다는 성취감을 제공한다.
- 제작 결과와 후일담을 통해 반복 플레이 동기를 만든다.

### 제품 검증 목표
- 의뢰 해석과 AI 무기 제작의 결합이 코어 재미로 작동하는지 검증한다.
- AI 생성 대기 시간이 플레이 흐름을 크게 훼손하지 않는지 검증한다.
- 태그 기반 평가가 플레이어에게 제작 성공/실패의 납득 가능한 피드백을 제공하는지 검증한다.

## 4. 타깃 사용자

주 타깃은 경영 시뮬레이션, 스토리텔링, 커스터마이징을 선호하는 10대 후반~30대 플레이어입니다. 생성형 AI 결과물과 조합 실험을 즐기는 캐주얼 유저를 부수 타깃으로 봅니다.

## 5. 핵심 가치 제안

**“손님의 말에서 정답을 추론하고, 내가 고른 원소와 스케치로 세상에 하나뿐인 무기를 만들어 결과를 확인한다.”**

## 6. 핵심 경험

상세 게임 규칙은 [GDD](/project/overview)를 기준으로 합니다. PRD에서는 다음 제품 경험만 요구합니다.

1. 의뢰를 이해할 수 있다.
2. 제작 의도를 원소와 스케치로 표현할 수 있다.
3. AI가 그 입력을 기반으로 무기를 생성한다.
4. 의뢰와 결과의 적합도를 태그 기반으로 평가할 수 있다.
5. 결과가 보상과 후일담으로 이어진다.

## 7. MVP 범위

### 포함
- NPC 의뢰와 요구 추론
- 태그 시스템 및 의뢰-무기 평가
- 원소 선택/조합과 제작 입력
- 스케치 기반 무기 제작
- 무기 대종류 직접 선택, 세부 종류 자동 판정
- VLM 없는 스케치 분석 파이프라인
- 생성 실패 재시도

### 제외 또는 후속
- 완전한 경제/성장 밸런스
- 원소 거래·숙련도·랭킹
- 원소 시너지·상극·혼합
- 생성 후보 비교 및 생성 후 부분 수정

## 8. 성공 지표

정량 목표값은 아직 확정하지 않습니다. 프로토타입/FGT 단계에서 최소 다음을 관찰합니다.

- 의뢰 요구를 이해하고 제작 방향을 세울 수 있는가
- 제작 입력이 결과에 반영됐다고 느끼는가
- 평가 결과를 납득하는가
- 다시 다른 무기를 만들어보고 싶은가
- AI 대기 시간이 이탈을 유발하는가

## 9. 주요 리스크와 가설

- AI 결과 품질이 입력 의도와 충분히 연결되지 않을 수 있다.
- 태그 평가가 지나치게 불투명하면 성공/실패를 납득하기 어렵다.
- AI 대기 시간이 코어 루프를 끊을 수 있다.
- 생성 비용과 로컬 모델 성능이 콘텐츠 확장성을 제한할 수 있다.

## 10. 로드맵

세부 일정과 담당은 WBS에서 관리합니다. 기존 PRD의 6개월 단계 계획은 현재 일정으로 자동 승격하지 않습니다.
