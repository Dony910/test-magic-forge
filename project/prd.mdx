# PRD

## 프로젝트 정의

**마법공방의 대장장이 (Magic Forge)**는 생성형 AI를 단순한 개발 보조 도구가 아니라 플레이어가 직접 조작하는 게임 메커닉으로 사용하는 상점 경영 게임입니다.

플레이어는 동서양 세계의 영웅들이 방문하는 대장간을 운영하며, 손님의 사연을 해석하고 원소와 스케치로 맞춤 무기를 제작합니다.

## 목표

### 사용자 가치

- 손님의 모호한 요구를 해석하는 추론의 재미를 제공한다.
- 직접 선택한 원소와 손그림이 완성 무기에 반영되는 창작 경험을 제공한다.
- 예상하지 못한 AI 결과를 실험과 발견의 재미로 전환한다.
- 제작한 무기와 그 후일담을 수집하고 공유할 동기를 만든다.

### 개발 목표

초기 개발의 최우선 목표는 **AI를 활용한 무기 제작 코어 루프가 실제로 재미있는지 검증하는 것**입니다. 완전한 경영 시스템이나 대규모 콘텐츠보다 의뢰 해석 → 제작 → 결과 확인의 경험을 먼저 검증합니다.

## 타깃

주 타깃은 가벼운 경영 시뮬레이션, 스토리텔링, 커스터마이징을 선호하는 10대 후반~30대 플레이어입니다. 생성형 AI 결과물과 조합 실험, 결과 공유에 흥미가 있는 캐주얼 유저도 부수 타깃으로 봅니다.

## 게임 구조

게임은 크게 **카운터(접객**)와 **공방(제작)** 사이를 오가는 영업 루프로 구성됩니다.

```text
NPC 방문
→ 대화 및 의뢰 해석
→ 공방 진입
→ 무기 대종류 선택
→ 원소를 이용한 스케치
→ 스케치 분석 및 AI 생성
→ 무기 전달
→ 평가/보상
→ 이후 후일담
```

## 핵심 시스템

### 내러티브 인터랙션

NPC의 요구사항은 직설적일 수도 있고 은유적일 수도 있습니다. 플레이어는 대화를 통해 필요한 무기의 형태와 성질을 추론합니다.

### 의뢰-무기 평가

NPC 의뢰가 요구하는 내부 조건과 완성 무기의 내부 데이터를 비교해 평가합니다. 태그 체계와 평가 공식의 최종 범위는 별도 확정이 필요합니다.

### 원소 시스템

원소는 무기 생성의 핵심 재료입니다. 원소의 이름, 설명, 색상과 조합 결과가 제작 결과의 테마와 속성에 영향을 줍니다.

### 스케치 기반 무기 제작

플레이어는 무기 대종류를 정하고 원소를 물감처럼 사용해 벡터 스케치를 작성합니다. 클라이언트에서 OpenCV와 수학 기반 전처리를 수행한 뒤 구조화된 특징값을 로컬 텍스트 LLM 및 생성 모듈에 전달합니다.

### 후일담

무기를 전달한 뒤 일정 시간이 지나면 NPC의 모험 결과가 돌아옵니다. 제작 결과가 의뢰에 얼마나 적합했는지에 따라 후일담과 보상이 달라지는 구조를 목표로 합니다.

## MVP 우선순위

1. NPC 의뢰를 받고 제작에 진입할 수 있다.
2. 보유 원소를 이용해 무기를 스케치할 수 있다.
3. 스케치와 원소 정보를 분석해 무기를 생성할 수 있다.
4. 생성 결과를 의뢰 흐름에 전달할 수 있다.
5. 제작 실패 시 입력을 유지한 채 재시도할 수 있다.
6. 실제 플레이 테스트를 통해 핵심 재미와 AI 대기 경험을 검증한다.

## 개발 단계

기존 PRD의 초기 로드맵은 기획 → Tech PoC → 프로토타입 → 알파 → 베타 → MVP 런칭의 단계로 정의되어 있습니다. 현재 구현 상태는 각 시스템의 **기능정의** 페이지를 최신 기준으로 확인합니다.
