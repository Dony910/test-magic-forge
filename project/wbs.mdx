## 1. 기준

- 기준 범위: **MVP 출시까지**
- 기준일: **2026-09-08**
- 제품 단계 기준: PRD의 `기획 → Tech PoC → 프로토타입 → 알파 → 베타 → MVP 런칭`
- 관리 계층: **큰 마일스톤 → 세부 마일스톤 → WBS 작업 → Plane 태스크**
- 기획/정책 Source of Truth: Mintlify
- 실행 관리: Plane
- 목표일: MVP 출시일 확정 후 Plane 일정과 함께 산정

### 마일스톤과 작업의 구분

**마일스톤은 프로젝트가 도달한 상태를 표현합니다.** 하나의 리뷰, 문서, 기능 구현, 재정리 같은 활동을 마일스톤으로 사용하지 않습니다.

- 마일스톤 예: `핵심 게임 구조 확정`, `Core Loop First Playable`, `Feature Complete`, `Content Complete`, `Release Candidate`
- 작업 예: `원소 시스템 리뷰`, `태그 시스템 구현`, `빠진 문서 작성`, `무기 생성 구조 재정리`, `PoC 수행`
- `리뷰`, `정리`, `수정`, `조사`, `작성`, `구현`, `검토`처럼 수행 행위를 나타내는 항목은 원칙적으로 WBS 작업 또는 Plane 태스크로 둡니다.
- 세부 마일스톤은 하나 이상의 작업 결과를 묶어 **검증 가능한 상태 변화**를 나타냅니다.
