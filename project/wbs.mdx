## 3. 핵심 의존성

```text
PRD/GDD
├─ 원소 시스템 ─┐
├─ 무기 시스템 ─┼→ 무기 제작 시스템 → 태그 기반 평가 → 후일담
├─ 태그 시스템 ─┤
└─ 내러티브/NPC ┘
```

- 태그 시스템은 의뢰 데이터와 무기 결과 모두에 의존합니다.
- 무기 제작은 원소/무기/스케치 분석 정의가 필요합니다.
- 평가/후일담은 태그 평가 결과를 입력으로 사용합니다.

## 4. 기존 WBS에서 확인된 작업군

기존 원본에는 다음 작업군이 존재했습니다.

- 프로젝트 상세 사양(PRD) 및 개발 파이프라인 확정
- AI 구현 방식 기술 조사 및 아키텍처 결정
- 원소 및 무기 모듈 시스템 데이터화
- 내러티브 기반 확립 및 세계관 세팅
- 원소 시스템 정의/콘텐츠
- 무기 시스템 정의/콘텐츠
- **태그 시스템 정의/콘텐츠**

태그 시스템은 기존 WBS에도 독립 작업으로 존재했으며, 2026-08-24 결정으로 MVP 핵심 시스템으로 확정되었습니다.

## 5. 완료 기준 원칙

### 기획 문서

`review`에서 문서 충돌과 TBD 항목을 검토한 뒤 사용자/책임자가 승인하면 `approved`로 전환합니다.

### 개발 기능

기능정의서의 `기획 상태`와 `구현 상태`를 분리하고, 구현 완료만으로 기획 승인으로 간주하지 않습니다.

## 6. 재계획 필요 항목

- 실제 MVP 목표일
- 각 작업의 담당자/책임자
- 현재 코드 기준 구현 상태 재확인
- 태그 시스템 구현 일정
- 평가/후일담 시스템 범위
- NPC/내러티브 콘텐츠 제작 일정
- FGT/프로토타입 검증 일정과 성공 기준
