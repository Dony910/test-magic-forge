# 마법공방의 대장장이

\*\*마법공방의 대장장이 (The AI Blacksmith)\*\*는 동서양 판타지와 무협이 교차하는 세계에서 손님의 의뢰를 해석하고, 원소와 스케치를 이용해 세상에 하나뿐인 무기를 제작하는 상점 경영 게임입니다.

프로젝트 코드명은 **Project FORGE**입니다.

## 플레이어의 역할

플레이어는 영웅을 직접 조종하지 않습니다. 차원의 교차로에 위치한 대장간에서 손님의 사연과 요구를 듣고, 적합한 무기를 제작해 전달하는 **관찰자이자 조력자**입니다.

핵심 재미는 다음 세 요소의 결합입니다.

- NPC 대화를 통해 요구 조건을 추론한다.
- 원소와 스케치로 의도한 무기를 만든다.
- 제작 결과가 의뢰와 얼마나 맞는지 평가받고 이후 결과를 확인한다.

## 핵심 루프

1. 영업 시작 후 NPC의 의뢰를 받는다.
2. 대화에서 필요한 무기의 성질과 형태를 추론한다.
3. 공방에서 무기 대종류와 원소를 선택하고 스케치한다.
4. 로컬 분석과 AI 파이프라인이 스케치를 해석해 무기를 생성한다.
5. 완성된 무기를 NPC에게 전달한다.
6. 의뢰 요구와 제작 결과의 일치도를 바탕으로 평가와 보상을 받는다.
7. 이후 후일담을 통해 의뢰 결과와 추가 보상을 회수한다.

## 제품 방향

| 항목 | 내용 |
| --- | --- |
| 장르 | 경영 시뮬레이션 / 샌드박스 크래프팅 / RPG 요소 |
| 플랫폼 | 모바일(iOS/AOS), PC(Steam) |
| 플레이 | 싱글 플레이 중심, 일부 비동기 네트워크 기능 |
| 핵심 입력 | NPC 의뢰, 원소, 무기 대종류, 스케치 |
| 핵심 출력 | 무기 이미지, 종류, 이름, 설명, 속성 및 내부 판정 데이터 |

## 주요 시스템

### 의뢰와 내러티브

NPC는 요구를 항상 직접적인 수치로 전달하지 않습니다. 플레이어는 대화와 상황을 해석해 어떤 무기가 필요한지 판단해야 합니다.

### 원소 시스템

원소는 제작의 재료이자 스케치의 색/성질을 결정하는 입력값입니다. 원소끼리 조합해 새로운 원소를 발견하는 기능도 포함합니다.

### 무기 제작

플레이어의 벡터 스케치를 로컬에서 분석하고, 압축된 형태 특징과 원소 정보를 AI에 전달해 세부 무기 종류와 결과물을 생성합니다.

### 무기 모듈

등록된 파츠의 형태 특징과 사용자 스케치를 비교해 유사 파츠를 찾고, 접합점과 조립 규칙을 이용해 자동 구성하는 구조를 설계하고 있습니다.
