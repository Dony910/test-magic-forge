# 무기 모듈 파이프라인

최신 기능정의서 기준의 파츠 분석·탐색·조립 흐름입니다.

## 분석

파츠 벡터 스트로크를 로컬에서 래스터화하고 실루엣 및 원소별 마스크를 생성합니다. OpenCV와 수학 연산으로 형태 특징을 추출·정규화한 뒤, 로컬 텍스트 LLM이 검증 가능한 자연어 설명과 검색 키워드를 생성합니다.

정량 데이터는 RDBMS에, 자연어 임베딩은 별도 텍스트 벡터 인덱스에 저장합니다.

## 탐색

1. 무기 종류, 파츠 종류와 접합 조건으로 후보를 하드 필터링합니다.
2. 정량 특징은 RDBMS 후보를 대상으로 인메모리 weighted distance를 계산합니다.
3. 설명과 키워드는 텍스트 벡터 인덱스에서 의미 검색합니다.
4. 두 결과를 병렬 실행하고 Reciprocal Rank Fusion으로 통합합니다.
5. 상위 후보를 정량 특징으로 재비교하고 최종 점수를 계산합니다.
6. 기준 점수 이상인 최고 후보를 자동 선택합니다.

정량 검색에는 별도 MLP 인코더나 수치 전용 vector DB를 사용하지 않습니다.

## 자동 조립

선택된 파츠는 parts\_assembly에 정의된 기준 파츠, 접합 관계, 위치, 크기, 회전과 출력 순서를 기준으로 자동 조립합니다. 필수 파츠 누락, 접합점 불일치, 허용 범위 초과와 캔버스 이탈은 실패로 처리합니다.

## 미확정

수치 특징 가중치, 검색 Top K, RRF 후보 수, 재정렬 Top K, 최소 최종 점수, 임베딩 모델과 조립 보정 허용 범위는 추가 확정이 필요합니다.
