# 무기 모듈 기능정의

## 1. 기능 개요

사용자 스케치에서 추출한 형태 특징과 등록 파츠 데이터를 비교해 가장 적합한 파츠를 자동 선택하고, 사전 정의된 접합/조립 규칙으로 최종 무기를 구성합니다.

## 3. 분석/인덱싱

파츠 스케치를 래스터화해 `shape_metrics`, `element_regions`, `stroke_metrics`를 계산합니다. 정량 특징은 RDBMS에 저장하고, 검증된 형태 설명/키워드는 텍스트 임베딩 인덱스에 등록합니다.

## 4. 파츠 탐색

```text
weapon_type / weapon_subtype / part_type
→ 조립 호환성 하드 필터
→ 정량 특징 검색 ┐
                  ├→ 후보 합집합 → RRF → 정량 재정렬 → 최종 선택
→ 의미 검색 ─────┘
```

### 정량 검색

`cv_metrics`를 고정 순서로 정규화한 float array로 구성하고 항목별 가중치를 적용한 distance를 계산합니다. 별도 수치용 MLP 인코더나 수치 전용 vector DB는 현재 사용하지 않습니다.

### 의미 검색

검증된 `overall_description`, `keywords`, 항목별 분석 문장을 임베딩해 의미 검색합니다.

### 최종 선택

정량/의미/키워드 유사도를 결합한 `final_score`가 최소 기준 이상인 최고 후보 하나를 자동 선택합니다. 동점 규칙은 기존 기능정의의 우선순위를 사용하되 최종 검토가 필요합니다.

## 5. 자동 조립

1. `parts_assembly`와 캔버스/기준 파츠 정보를 조회합니다.
2. 필수 파츠가 모두 존재하는지 확인합니다.
3. 기준 파츠를 배치합니다.
4. `anchor_point` 관계에 맞춰 나머지 파츠를 연결합니다.
5. 위치·크기·회전 보정값을 허용 범위 내 적용합니다.
6. `draw_order`를 적용해 최종 자산을 합성합니다.
7. 실제 조립 데이터를 저장하고 검증합니다.

## 6. 예외

- 정량 특징 저장 실패: 검색 가능 상태 전환 차단

- 최종 점수 기준 미달: 기본 파츠 또는 탐색 실패 처리 정책 TBD
