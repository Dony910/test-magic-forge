# 무기 콘텐츠 정의

현재 콘텐츠 시트에 등록된 무기 분류와 파츠 정의입니다. 초기 콘텐츠 범위는 **검**과 **창** 계열을 중심으로 구성되어 있습니다.

## 무기 분류

| 대분류 | 소분류 | 필수 파츠 | 선택 파츠 |
| --- | --- | --- | --- |
| 검 | 대검 | 칼날, 가드, 손잡이 | - |
| 검 | 한손직검 | 칼날, 가드, 손잡이 | - |
| 검 | 단검 | 칼날, 손잡이 | - |
| 창 | 장창 | 창날, 손잡이 | - |
| 창 | 폴암 | 창날, 손잡이 | - |
| 창 | 랜스 | 창날, 손잡이 | 기타(랜스 방패) |

## 데이터 관리 원칙

- 대분류는 플레이어가 제작 진입 시 선택하는 범주입니다.
- 소분류는 최신 제작 기획 기준 AI/시스템이 자동 판정합니다.
- 파츠 공유 가능 범위를 명시해 자산 중복을 줄입니다.
- 실제 탐색 전 `weapon_type`, `weapon_subtype`, `part_type`과 조립 호환성으로 후보를 하드 필터링합니다.
- 파츠마다 형태 특징과 `anchor_points`를 별도 데이터로 보유해야 합니다.
