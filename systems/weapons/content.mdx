# 무기 콘텐츠 정의

## 1. 콘텐츠 목적

무기 시스템이 자동 판정·검색·조립에 사용할 **무기 분류와 파츠 콘텐츠 목록**을 정의합니다. 플레이어가 세부 종류를 직접 선택하는 UI 목록이 아니라 시스템이 판정할 수 있는 콘텐츠 사전입니다.

## 2. 콘텐츠 분류 체계

- `대분류`: 플레이어가 제작 진입 시 직접 선택하는 상위 범주
- `소분류`: 스케치 분석 결과를 기반으로 시스템이 자동 판정하는 세부 종류
- `파츠 구분`: 칼날, 가드, 손잡이, 창날, 기타 등 조립 단위
- `필수 여부`: 해당 소분류 완성에 반드시 필요한지 여부
- `공유 가능 소분류`: 동일 파츠 자산을 재사용할 수 있는 범위

## 5. 콘텐츠 제작 규칙

- 대분류/소분류/파츠 구분을 명확히 지정합니다.
- 각 소분류의 필수 파츠 집합을 반드시 정의합니다.
- 공유 가능한 파츠는 범위를 명시해 자산 중복을 줄입니다.
- 탐색 대상 파츠는 형태 특징과 `anchor_points`를 별도 데이터로 가져야 합니다.
- 신규 소분류를 추가하면 자동 판정 기준과 조립 규칙도 함께 검토합니다.

## 6. 품질 기준

- 필수 파츠 정의가 누락되지 않아야 합니다.
- 파츠 ID는 고유해야 합니다.
- 공유 범위가 조립 호환성과 모순되지 않아야 합니다.
- 콘텐츠 목록은 시스템 정책과 구현 알고리즘을 직접 정의하지 않습니다.

## 7. 미확정

- MVP에 포함할 최종 대분류/소분류 수
- 신규 무기 종류 추가 우선순위
- 파츠별 형태 특징/접합점 등록 완료 기준
