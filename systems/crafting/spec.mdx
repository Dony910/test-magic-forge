# 무기 제작 기능정의

최신 기능정의서를 기준으로 클라이언트 드로잉 기능은 대부분 구현 완료이며, 전처리 분석과 AI/서버 생성 파이프라인은 코드 리뷰 또는 문서 검토 단계가 많습니다.

## 구현 상태

| 영역 | 주요 상태 |
| --- | --- |
| 제작 화면 진입 | 구현 완료 / 코드 리뷰중 |
| 무기 대종류 UI | 구현 완료 |
| 보유 원소 팔레트 | 구현 완료 |
| 사용 원소 수 제한/잠금 | 구현 완료 |
| 벡터 스케치 도구 | 구현 완료 |
| 스트로크 데이터 저장 | 구현 완료 |
| 주원소 지정 | 구현 완료 |
| 필수 입력 검증 | 대부분 구현 완료, 안내 일부 미시작 |

## 상태 머신

```text
Draft
→ Validating
→ Generating
→ Success
   또는 Failed
```

- `Draft`: 제작 입력 중
- `Validating`: 제작 요청 검증 중
- `Generating`: AI 생성 진행 중
- `Success`: 생성 성공
- `Failed`: 생성 실패

## 확정된 주요 정책

- 최소 실제 사용 원소 수는 1개입니다.
- 주원소는 최대 1개입니다.
- 사용자가 선택하는 것은 무기 대종류이며 세부 종류는 자동 판정합니다.
- 원소가 겹치면 마지막 원소가 덮어쓰며 MVP에서 혼합하지 않습니다.
- MVP에서 원소는 제작 시 소모하지 않습니다.
- 이미지/Base64 VLM 입력은 사용하지 않습니다.
- 생성 성공 시 결과는 즉시 확정합니다.

## 후속 확정 필요

`MAX_SELECTABLE_ELEMENTS_BY_SHOP_LEVEL`, `GENERATION_RETRY_LIMIT`, `GENERATION_TIMEOUT`, 주원소 자동 판정 가중치, 분석 정규화 규칙과 품질 검증 기준은 아직 확정이 필요합니다.
