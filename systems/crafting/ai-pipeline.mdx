# 스케치 분석과 AI 파이프라인

현재 기술 방향은 **VLM 없이 로컬 텍스트 LLM을 사용하는 구조**입니다. 이미지 또는 이미지 Base64를 LLM에 직접 전달하지 않습니다.

## 전체 흐름

벡터 스트로크를 로컬에서 래스터화하고 전체/원소별 마스크를 만든 뒤 OpenCV와 수학 연산으로 특징을 추출합니다. 스트로크 요약값과 함께 구조화 데이터로 압축한 뒤 로컬 텍스트 LLM이 세부 무기 종류, 파츠 후보와 원소 영향 범위를 해석합니다.

## 전체 형태 특징

- 가로/세로 비율
- 바운딩 박스와 중심
- 무게 중심
- 좌우/상하 면적 비율
- 세로/가로 대칭 점수
- 직선도
- 주요 윤곽선 수
- 연결된 주요 덩어리 수

## 원소별 특징

각 원소는 최종 렌더링 상태의 별도 마스크를 기준으로 면적 비율, 중심, 바운딩 박스, 좌우/상하 분포와 연결 영역 수를 계산합니다.

## 스트로크 특징

유효 스트로크 수, 총 길이, 평균 브러시 굵기, 방향 비중, 교차 지점 수와 단순화 윤곽선을 계산합니다. 단순화 윤곽선 핵심점 수는 현재 16~64개가 제안되어 있으며 최종 확정이 필요합니다.

## AI 입력

구조화 분석값과 함께 무기 대종류, 실제 사용 원소 목록, 원소별 노출 비율, 주원소, NPC 의뢰 정보, 무기 종류/파츠 정의와 생성 규칙을 전달합니다.

## AI 출력

- 세부 무기 종류
- 파츠 구성과 배치 정보
- 원소별 반영 정보
- 주원소
- 무기 이름과 설명
- 속성 및 태그
- 생성 추적 ID

계산 가능한 수치 특징은 클라이언트에서 먼저 계산하고, LLM은 압축된 특징의 의미 해석과 분류·생성에 집중하도록 역할을 분리합니다.
