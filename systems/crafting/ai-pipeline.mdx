# 스케치 분석과 AI 파이프라인

## 1. 확정 기술 방향

**VLM을 사용하지 않습니다.** 이미지 또는 이미지 Base64를 LLM에 직접 전달하지 않습니다. 벡터 원본 좌표 전체도 텍스트 LLM에 그대로 전달하지 않습니다.

```text
벡터 스트로크
→ 로컬 래스터화
→ 전체/원소별 마스크
→ OpenCV 및 수학 특징 추출
→ 스트로크 요약 및 윤곽선 단순화
→ 구조화 JSON
→ 로컬 텍스트 LLM
→ 세부 무기 종류/파츠/원소 영향/메타데이터 해석
```

## 2. 전체 형태 특징

- 가로/세로 비율
- 바운딩 박스와 중심
- 무게 중심
- 좌우/상하 면적 비율
- 세로/가로 대칭 점수
- 직선도
- 주요 윤곽선 수
- 연결 영역 수

## 3. 원소별 특징

최종 렌더링 상태의 원소별 마스크에서 면적 비율, 중심, 바운딩 박스, 좌우/상하 분포와 연결 영역 수를 계산합니다.

## 4. 스트로크 특징

- 유효 스트로크 수
- 총 길이
- 평균 브러시 굵기
- 방향 히스토그램
- 교차 지점 수
- 단순화 윤곽선

단순화 윤곽선 핵심점 수는 TBD입니다. 기존 문서의 16~64개는 제안값으로만 유지합니다.

## 5. LLM 입력

- 무기 대종류
- 형태 분석값
- 원소별 영역 분석값
- 스트로크 요약값
- 실제 사용 원소
- 주원소
- NPC 의뢰 정보
- 무기 종류/파츠 정의
- 생성 규칙

## 6. LLM/생성 출력

- 세부 무기 종류
- 파츠 구성 및 배치 정보
- 원소별 반영 정보
- 주원소 자동 판정 결과(미지정 시)
- 이름/설명/속성
- 평가용 태그

## 7. 역할 분리 원칙

계산 가능한 수치는 클라이언트/로컬 분석 모듈에서 계산합니다. LLM은 계산기가 아니라 압축된 특징의 의미 해석, 분류, 구조화 생성에 집중합니다.

## 8. 미확정

- 특징값 최종 필드
- 각 특징의 정규화 기준
- 단순화 윤곽선 핵심점 수
- 주원소 자동 판정 가중치
- 생성 품질 검증 기준
- 태그 출력 스키마
