# 무기 제작 시스템

무기 제작 시스템은 플레이어가 **무기 대종류를 선택하고 원소를 물감처럼 사용해 스케치한 뒤**, 로컬 분석과 AI 생성 파이프라인을 통해 완성 무기를 만드는 핵심 시스템입니다.

## 제작 흐름

```text
제작 진입
→ 무기 대종류 선택
→ 보유 원소 팔레트 표시
→ 원소별 벡터 스케치
→ 주원소 지정(선택)
→ 입력 검증
→ 로컬 전처리 분석
→ 구조화 JSON 생성
→ AI 분석/생성
→ 결과 검증
→ 결과 즉시 확정
```

## 입력 우선순위

현재 기획에서는 제작 결과에 대한 영향도를 다음과 같이 봅니다.

1. **원소**: 색상, 특수 효과, 설정, 이름/설명, 속성과 전체 디자인 무드
2. **무기 대종류**: 결과가 가져야 할 구조적 범위 제한
3. **스케치**: 전체 실루엣과 파츠 배치 및 비율

## 원소 팔레트

- 스케치 화면에 보유한 사용 가능 원소 전체를 표시합니다.
- 별도 사전 선택 없이 원소를 선택해 바로 그릴 수 있습니다.
- 캔버스에 존재하는 서로 다른 원소 수를 실시간 계산합니다.
- 최대 N종에 도달하면 아직 사용하지 않은 원소는 잠깁니다.
- 원소가 지우기/Undo로 완전히 사라지면 사용 수가 감소하고 잠금이 풀립니다.
- 최종 생성 요청에는 캔버스에 실제로 남은 원소만 포함합니다.

## 스케치

지원 도구는 브러시, 지우개, 브러시 굵기, Undo/Redo, 전체 지우기, 원소 전환, 확대/축소와 캔버스 이동입니다.

각 스트로크는 최소 다음 데이터를 저장합니다.

```text
stroke_id
 element_id
 points
 brush_size
 draw_order
 erase_data
```

서로 다른 원소가 같은 위치에 겹치면 마지막으로 칠한 원소가 덮어씁니다. MVP에서는 원소 혼합, 시너지와 상극 반응을 적용하지 않습니다.

## 주원소

주원소는 완성 무기의 대표 속성과 디자인 방향에 가장 큰 영향을 주는 하나의 원소입니다.

- 실제 사용 원소 중 하나만 지정 가능
- 지정은 선택 사항
- 미지정 시 시스템이 면적, 위치와 스트로크 비중을 참고해 자동 판정

## 제작 요청 검증

- 실제 사용 원소가 하나 이상 존재해야 합니다.
- 무기 대종류가 선택되어야 합니다.
- 유효한 벡터 스트로크가 존재해야 합니다.
- 주원소가 지정됐다면 실제 사용 원소에 포함되어야 합니다.

실패 시 요청을 보내지 않고 기존 스케치와 선택 정보를 유지합니다.

## 결과와 실패

MVP에서는 생성 성공 시 결과를 즉시 확정합니다. 여러 후보 비교, 생성 후 부분 수정은 범위에서 제외합니다.

AI 응답 실패, 타임아웃, 필수값 누락, 무기 대종류 불일치나 유효성 검증 실패가 발생하면 입력을 유지하고 동일 데이터로 재시도할 수 있습니다.
