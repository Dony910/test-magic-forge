# 원소 시스템

원소는 무기 제작의 핵심 재료이자 AI 생성 결과를 통제하기 위한 게임 내부 입력 단위입니다. 이름, 설명과 색상 정보를 가지며 무기의 외형, 설정과 디자인 무드에 영향을 줍니다.

## 기획 목적

- 생성형 AI 입력을 게임 규칙 안에서 통제 가능한 재료 단위로 제공한다.
- 의뢰를 해석한 플레이어가 적절한 원소를 고르게 해 선택의 의미를 만든다.
- 두 원소를 조합해 새로운 원소를 발견하는 실험과 수집의 재미를 만든다.
- 이미 발견한 조합은 재사용해 결과 일관성을 보장하고 AI 비용을 줄인다.

## 핵심 개념

| 개념 | 정의 |
| --- | --- |
| 원소 | 무기 제작에 사용하는 재료. 이름, 설명, 색상 정보를 가진다. |
| 기본 원소 | 초기 진행에서 제공되는 기초 원소 |
| 조합 원소 | 두 원소를 조합해 생성된 원소 |
| 희귀 원소 | 후일담, 이벤트 등 특수 경로를 통해 획득하는 확장 원소 |
| 조합 키 | 두 원소 ID를 정렬해 생성하는 순서 비의존 검색 키 |

## 원소 조합

MVP의 조합 입력 수는 **2개**입니다. 조합 순서는 결과에 영향을 주지 않습니다.

```text
원소 A + 원소 B 선택
→ 보유/사용 가능 상태 검증
→ ID 정렬 및 combination_key 생성
→ ElementRecipeData 우선 조회
→ 기존 조합: 저장된 결과 반환
→ 신규 조합: AI 생성
→ 결과 검증
→ ElementData / ElementRecipeData 저장
→ 유저 보유 원소 추가
```

동일 조합은 항상 기존 결과를 재사용하므로 공략과 공유가 가능합니다.

## AI 신규 원소 생성

DB에 조합 결과가 없을 때 AI가 신규 원소를 생성합니다.

### 입력

- 두 원소의 이름
- 두 원소의 설명
- 두 원소의 색상
- 세계관 톤
- 출력 JSON 스키마

### 필수 출력

```json
{
  "name": "화염강",
  "description": "불꽃의 열기가 강철 내부에 스며든 붉은 금속 원소",
  "color_hex": "#D94A2B"
}
```

### 검증

- `name`은 비어 있지 않고 최대 12자
- `description`은 비어 있지 않아야 함. 최대 길이는 추가 확정 필요
- `color_hex`는 유효한 HEX 형식
- 기존 원소명과 중복 여부 확인
- 금칙어와 세계관 톤 검증

## 제작에서의 원소 사용

최신 무기 제작 기능정의에서는 보유 원소 전체를 스케치 팔레트에 표시하고, 캔버스에 **실제로 남아 있는 서로 다른 원소 수**를 기준으로 최대 사용 수를 제한합니다.

과거 원소 기획서의 ‘영업 시작 전 원소 사전 보관’ 규칙과 충돌하므로 최종 정책은 [결정 필요 항목](/project/decisions)을 참고합니다.

## MVP 제외/확장

원소 도감, 최초 발견자, 거래, 숙련도와 랭킹은 현재 원소 시스템 MVP 외부의 확장 기능입니다. 태그는 다른 시스템과 연결 범위를 추가 확정해야 합니다.
