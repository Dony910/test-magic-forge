Game elements are the smallest, reusable units of design you create in Magic Forge. Think of them as the nouns and verbs of your game: a playable hero, a healing potion, a double-jump ability, or the boss arena in level three. By breaking your design into discrete elements, you can balance, version, and link them together so nothing lives in a vacuum.

## Built-in element types

Magic Forge ships with five core types. You can extend these or create entirely custom types from the project settings.

## Element properties

Every element has a standard set of fields, plus type-specific attributes you define yourself.

| Property | Description |
| --- | --- |
| Name | The display name of the element. Must be unique within its project. |
| Description | A short paragraph explaining what the element is and how it functions in gameplay. |
| Type | The element type: character, item, ability, level, or a custom type you created. |
| Tags | Filterable labels such as "Rare", "Melee", or "BossEncounter". |
| Attributes | Key/value pairs for numeric or text data: health, damage, weight, rarity tier, and so on. |
| Relationships | Links to other elements: an item owned by a character, an ability unlocked at a level. |

## Nested attributes

Complex designs need more than flat key/value pairs. Magic Forge supports nested attribute objects so you can model hierarchies like upgrade trees or gear sets.

```json
{
  "name": "Void Fang",
  "type": "weapon",
  "attributes": {
    "base_damage": 42,
    "scaling": {
      "strength": 0.8,
      "dexterity": 0.4
    },
    "effects": [
      {
        "trigger": "on_hit",
        "type": "life_drain",
        "value": 5
      }
    ]
  }
}
```
